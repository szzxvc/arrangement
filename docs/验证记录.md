## 数据库、权限和并发

Vitest 使用 Miniflare 运行 Worker，加载真实迁移并通过 HTTP API 操作真实 D1；数据库不使用 mock。

已验证：

- 正常注册与登录、中文／空格密码、8–128 字符边界、用户名规范化、错误密码统一提示；并发同名注册最终只有一个账号和一个对应会话。
- Cookie 的 HttpOnly／Secure／SameSite=Lax；会话刷新、到期与退出撤销；未登录读写拒绝。
- 项目列表和详情隔离，非成员猜项目、预约、目标记录标识不能操作。
- 邀请前后权限差异、被邀请本人接受、并发接受只加入一次、拒绝后再邀请、接受和拒绝竞争不产生半加入成员。
- **20 名真实已加入成员并发开始同一项目：只有一项成功，其余 19 项返回合理的 PROJECT_BUSY；直接 SQL 查询最终只有一条未结束工作和一条开始审计。**
- 不同项目可独立开始；本人重复开始返回原记录；普通结束无法结束他人；旧工作 UUID 不能结束下一轮。
- 开始、结束、预约、强制操作的相同请求标识重放；不同参数复用标识拒绝；没有重复工作、预约或审计。
- 普通成员强制开始／结束，真实操作人和目标被记录；项目占用时强制开始拒绝；旧确认和状态来回变化后旧版本拒绝。
- 普通开始与强制开始混合并发仍满足互斥；普通结束和强制结束竞争只产生一次结束审计。
- **20 名成员并发预约同一空闲时段：只有一项成功；直接 SQL 连接查询确认有效预约没有重叠。**
- 相同、左侧交叠、右侧交叠、包含、被包含、本人重叠均拒绝；首尾相接允许；过去、反向、零长度和非整分钟拒绝。
- 本人取消、他人／非成员无法取消、取消后重新预约、取消与创建竞争符合数据库提交顺序。
- 直接 SQL 修改预约时间、项目、取消状态恢复仍受到更新触发器保护；约束失败后原数据保留。
- 预约创建、取消和到期不改变实际工作；当前时段由他人预约仍可在无人实际工作时手动开始。
- 条件更新零行不会留下审计；后续 SQL 失败回滚主变更；实际打卡时间来自服务端；预约和操作历史分页。
- **销毁再重启 Worker／Miniflare 后，同一个持久 D1 目录中的账号、会话、成员、预约和工作状态保留。**
- Origin、Sec-Fetch-Site 和 CSRF 校验，账号与地址持久限流，JSON 未知接口和私有 `no-store`。

## 时间与浏览器

- UTC+8 显式解析，非法日期与非分钟精度拒绝，闰年、跨月、跨年、北京时间午夜边界与“今天”简写。
- 在 `America/Los_Angeles` 浏览器时区输入 2030-01-01 00:00，北京时间转换后数据库为对应 UTC 秒数，未使用浏览器本地偏移。
- 完整多用户流程：邀请、接受前隔离、开始冲突、取消确认不发修改请求、普通成员强制改状态、跨年预约、前端冲突提示、取消、历史与审计。
- **360、390、768、1440 像素视口**都完成创建、打卡、预约和取消；长用户名、80 字项目名、2000 字描述、日期弹窗没有整页或弹窗横向溢出。
- 原生 dialog 的 Escape 取消和焦点返回；项目深链刷新；退出后登录回到请求路径；外部／反斜杠等无效返回路径被拒绝。
- 用户输入 `<img ...>` 与 `<script ...>` 按文本展示，没有执行脚本。
- 模拟服务器已提交后第一次响应丢失，自动重试复用同一请求标识，最终只有一次开始审计。
- 浏览器断网时不虚报工作结束；显示结果未确认与同步失败；联网后立即恢复同步。
- 控制浏览器可见状态验证隐藏时停止轮询，恢复可见立即请求；故意延迟旧快照，验证新操作结果不会被旧响应覆盖。

## 密码派生与资源

本地真实 Workers runtime 执行 `node:crypto.scryptSync`，参数如下：

```text
N=16384, r=8, p=5
16 字节随机盐，64 字节派生结果
maxmem=67108864（64 MiB）
```

最终工具链的三次本地墙钟测量：**201、189、187 毫秒**。此前较空闲的本地运行曾测得 147、135、134 毫秒；并行构建和测试负载会影响墙钟时间。上述数值不是 Cloudflare 边缘 CPU 时间或峰值内存数据。

保存算法和参数，恒定时间比较，未降低强度。`maxmem` 是 scrypt 配置上限，不是测得的进程或 isolate 峰值内存。默认以 Workers Paid、30 秒 CPU 上限为运行基线；不承诺免费 CPU 预算适用。

- D1：`club-work-checkin-free-db`，迁移执行 24 条命令，`0001_initial.sql` 成功。

云端通过 19 项 HTTP 验收：首页、SPA 深链、未登录拒绝、注册、三次退出及重新登录、会话读取、项目列表、项目创建、开始、工作快照、结束、预约、取消预约与最终退出。确认了 CSP 和 HttpOnly／Secure Cookie。验收账号使用随机密码，不写入文档、源码或请求日志；其私有验收项目没有正在进行的工作或有效预约。

Workers Tail 记录本次请求均为 `ok`，没有 `exceededCpu`。**注册 CPU 为 182 毫秒，三次登录分别为 181、194、183 毫秒；普通业务操作约 1–8 毫秒。** 这些是云端日志的 CPU 字段，不是本地墙钟耗时。

Free 的官方单次请求限制为 [10 毫秒 CPU](https://developers.cloudflare.com/workers/platform/limits/)。本次认证明显超过该额度，因此这次功能成功不能证明免费套餐可稳定运行。用户已在控制台确认当前套餐为 **Workers Free**；OAuth 对账单订阅接口返回 403，未通过 API 独立核实套餐。部署保留现有密码派生强度。
